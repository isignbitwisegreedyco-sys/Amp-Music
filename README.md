# Amp-Music

A lightweight browser music player for direct cloud audio links and music stored on your device.

## Run

Open `index.html` in a modern browser. No installation, account, or server is required.

## Use

- Add a direct `http` or `https` audio URL to keep a cloud track in this browser's library.
- Select or drop audio files to play them locally. Local files are not uploaded and are only available until the page is closed.
- Select a library track to play, then use the bottom controls to pause, seek, change volume, or move through the queue.

Cloud playback uses the browser's native audio streaming. The link must be directly accessible as audio; a cloud-sharing webpage, sign-in flow, or provider that blocks browser playback will not work. Cloud links are saved in local browser storage, not uploaded to Amp.
